The project contains the following: 
1) Feko script to simulate the current distribution on the surface of a circular waveguide aperture by creating an array of infinitesimal magnetic dipoles:
•	To perform FEKO simulation, the current distribution on the surface of the waveguide aperture was modeled by an array of infinitesimal magnetic dipoles. The current strength of each is determined by the field distribution at the respective locations of the dipoles. The separation between any adjacent dipoles was lambda/8 which gives quite good results. The model of the current distribution is generated by the given script developed in the FEKO editor. 
•	To run the script the user must edit it in the Feko script editor.
2) Matlab code to compute the near field Ey radiated from the circular waveguide aperture mounted on a ground plane for TE11 mode.
The program computes Ey for TEmn mode waveguide antenna, m=1, n=1
at height z = 10*lambda in the plane y = 0 (0<x<10*lambda)
the radius of the antenna is a = 5**lambda
ph is the angle in azimuth direction
